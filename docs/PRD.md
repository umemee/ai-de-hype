# PRODUCT REQUIREMENTS DOCUMENT (PRD)

## 1. 서비스 개요
- **서비스명**: AI De-Hype
- **서비스 정의**: 빅테크 공식 문서와 검증된 오픈소스를 1차 소스로 삼아, AI 역량을 게임처럼 레벨업하며 학습하는 자기주도형 성장 플랫폼
- **핵심 가치**:
  1. SNS 인플루언서의 2차 가공 과장 광고를 빅테크 1차 공식 문서(프롬프트 가이드, 쿡북)로 대체하여 스스로 판단하는 안티 하이프(De-Hype) 리터러시 확립
  2. 4대 핵심 역량 매트릭스 기반 20레벨 게이미파이드 진단 및 실습 성장 로드맵 제공
  3. 맥락과 사용 시나리오가 담긴 상시 열람형 개인화 오픈소스 도구 참고서 제공
- **타깃 페르소나 (3대 핵심 타깃)**:
  - **Persona A (10~20대 비전공자 / 학생 / 1인 입문자)**: 터미널 에러 꼬임, 가짜 논문 인용, 과제 대행 학습 결손(Net-zero), 과금 폭탄 공포를 겪는 입문자
  - **Persona B (40~50대 직장인 / 실무 관리자 / 자영업자)**: 알맹이 없는 AI Slop 검토 피로, 사내 규정 충돌, 대용량 엑셀 결측치 왜곡, ROI 입증 부담, 보안 유출 혼란을 겪는 실무 책임자
  - **Persona C (SNS/숏폼 도구 접촉 일반 사용자)**: 숏폼의 "이 도구 안 쓰면 손해" 콘텐츠를 보고 시도했다가 숨겨진 비용(토큰 소모, 개별 연동 번거로움)에 좌절하고, GitHub star만 누른 뒤 잊어버리는 일반 사용자

---

## 2. 4대 핵심 역량 매트릭스 (Growth Pillars)
사용자를 단순 점수로 줄 세우지 않고, 게임의 4각형 스탯 트리로 시각화:
1. **실행 및 복구력 (Execution & Rollback)**: CLI 환경 탐색, 터미널 에러 로그 해석, Git 체크포인트 롤백, API 호출 예외 처리 및 과금 상한선(Hard Limit) 설정 역량
2. **출처 및 수치 검증력 (Verification & Grounding)**: 환각(가짜 논문, 사건번호, 저자) 1차 DB 교차 대조, 대용량 엑셀 결측치 정제, 통계 수치의 원본 역추적 역량
3. **비판적 사고 & 안티 슬롭 (Critical Thinking & Anti-Slop)**: 무의미한 미사여구 필터링, 정량적 제약 조건 및 구조화된 출력 강제, 인플루언서 콘텐츠의 과장/은폐 요소를 스스로 식별하는 역량, Net-zero Learning 방지 루틴
4. **데이터 거버넌스 & 안전 (Data Context & Safety)**: 사내 규정집 시계열 버전 분리, 비식별화 및 Opt-out 검증, 조직 단위 도입 ROI 지표 설계 역량

## 3. 화면 구성 및 핵심 기능 명세

### 1) Intro Section (메인 인트로)
- **상단 헤더**: 서비스 로고 및 전 연령대 가독성 보장을 위한 [글자 크기: 보통 / 크게] 토글 버튼 (`fontSizeMode`)
- **서비스 비전 배너**: 빅테크 공식 문서 1차 소스 기반 레벨업 및 자기주도형 실습 성장 플랫폼 취지 안내
- **4대 성장 축(스탯) 프리뷰**: 01~04 인덱스 헤더 기반 핵심 진단 영역 카드
- **CTA 버튼**: [내 맞춤 학습 경로 진단하기 (3분)] 메인 액션 및 [오픈소스 실습 도감 보기] 보조 액션

### 2) Quiz Section (진단 워크시트)
- **문항 총량 규격**: 총 6~8문항 체제 (4대 역량 축당 1~2문항, 검증된 문항만 수록)
- **이론 및 실기 균형**: 축당 개념 이해를 묻는 이론형 2~3문항, 실무 시나리오 기반 실기형 2~3문항 배분
- **어휘 안전망(Lexical Safety Net)**: 롤백, DOI, 하드 리밋, AI 슬롭 등 필수 기술 용어에 점선 밑줄 및 일상 비유 해설 팝오버 상시 제공
- **상단 프로그레스 바**: 현재 문항 번호(`font-mono`) 및 백분율 진행 바 (`Question 01 / 20`)
- **4지선다 선택지**: 모바일 44px+ 터치 안전망이 확보된 flat border 카드 (선택 시 0.3초 딜레이 후 다음 문항 부드러운 전환)
- **하단 네비게이션**: [이전 문항으로] 및 [진단 종료] 조작 지원

### 3) Loading Section (모노톤 분석 파이프라인)
- **진단 분석 타임라인 (정확히 2.5초 고정)**:
  - 1단계 (0.0~0.8초): "제출하신 실무 판단 응답을 분석하고 있습니다..."
  - 2단계 (0.8~1.6초): "4대 핵심 통제 역량(실행 복구·출처 검증·안티 슬롭·거버넌스)을 평가하는 중입니다..."
  - 3단계 (1.6~2.5초): "회원님의 수준에 꼭 맞는 0원 실습 경로와 추천 도구를 매칭하고 있습니다..."
- **비주얼**: 네온이나 그라디언트 없는 순수 zinc 모노톤 스켈레톤 UI (`animate-pulse`) 및 `animate-in fade-in` 텍스트 트랜지션

### 4) Result Section (결과 리포트 및 액션플랜)
- **종합 진단 스탯**:
  - 4대 영역 균등 평균 기반 종합 점수 (0~100점, 5점 단위)
  - 20레벨 1:1 매핑 체계 (Lv. 1 ~ Lv. 20) 및 4개 구간 티어 타이틀:
    * 0~39점: Lv. 1~5 (블랙박스 의존 단계)
    * 40~69점: Lv. 6~10 (실행 및 탐색 단계)
    * 70~89점: Lv. 11~15 (실무 통제자 단계)
    * 90~100점: Lv. 16~20 (AI 아키텍트 단계)
  - 4대 성장 축별 세부 득점률 게이지 바 (모노톤 zinc 바)
- **1:1 심층 소견서**: Gemini API 실시간 분석 기반 강점 분석 및 최우선 성장 목표 조언
- **실사용 현실적 조언 박스**: `border-l-4 border-l-amber-600` 액센트 기반의 실무 제약 및 현실적 조언 팁
- **타깃별 3대 실습 트랙 선택 탭**:
  - [트랙 A. 비전공 1인 빌더] / [트랙 B. 연구·글쓰기] / [트랙 C. 실무 관리자]
  - 탭 전환 시 선택한 트랙에 맞는 공식 문서(1차 소스) 기반 추천 실습 튜토리얼 및 오픈소스 동적 렌더링
- **액션**: [진단 다시 하기] (상태 초기화 및 인트로 복귀) 및 [진단 결과 텍스트 복사하기]

### 5) Tools Section (오픈소스 도구 참고서 - Reference Library)
- **역할 및 진입**: 진단 완료 여부와 무관하게 언제든 상시 열람 가능한 개인화된 오픈소스 참고서
- **수록 규모**: 실사용 빈도가 높고 공식 문서가 검증된 대표 오픈소스 5~6종 수록
- **콘텐츠 구조**:
  - 도구명, 분야 태그, 타깃 트랙
  - "언제 필요한가 (사용 시나리오)" 1줄 명확 제공
  - 하드웨어 권장 사양 및 설치 소요 시간 (`font-mono` 수치)
  - "시작 전 꼭 알아둘 현실적 조언": 단순 과장광고 비난이 아닌 장점과 실사용 제약(토큰 소모, 개별 연동 번거로움 등)의 균형 잡힌 실무 팁 제공
  - 공식 가이드 및 쿡북 링크

### 6) Coach Section (AI 활용법 코치)
- **진입**: 헤더 네비게이션에 상시 노출. 진단 미완료 상태에서도 접근 가능.
- **빈 입력창 방지**: 화면 진입 시 예시 질문 3~4개를 클릭 가능한 칩(chip) 형태로 미리 노출
  (예: "이메일 초안 빨리 만들고 싶어요", "MCP가 뭔지 모르겠어요")
- **개인화**: 진단을 완료한 사용자는 user_level, weak_axis가 자동으로 /api/coach 요청에 포함되어
  설명 난이도가 자동 조정됨을 화면에 작게 명시 (예: "회원님의 Lv.8 기준으로 설명합니다")
- **답변 렌더링**: 답변 하단에 cited_sources를 도감 카드로 연결되는 링크 chip으로 표시
- **범위 밖 질문**: in_scope: false 응답 시 "이 서비스는 AI 도구 활용 관련 질문만 답합니다" 안내를
  경고 색상(amber-600) 없이 중립 톤으로 표시 (사용자를 혼내는 느낌 금지)
- **장애 상태**: fallback_used: true 응답 시 화면 상단에 작은 안내
  ("현재 실시간 분석이 지연되어 기본 안내를 보여드립니다") 표시
